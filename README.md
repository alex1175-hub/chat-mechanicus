# Chat Mechanicus

Aplicación Flutter de demostración con una interfaz inspirada en una consola
noosférica del Adeptus Mechanicus. Incluye navegación inferior entre Peoples,
Chats y Calls, datos de ejemplo y búsqueda local.

## Requisitos

- Flutter SDK compatible con la restricción de Dart indicada en `pubspec.yaml`.

## Ejecutar

```shell
flutter pub get
flutter run
```

## Validar

```shell
flutter analyze
flutter test
```

Los contactos, conversaciones, llamadas y avisos son simulados; no se conecta a
servicios externos.
